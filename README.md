# DayRhythm Web

Браузерная версия DayRhythm AI на Next.js, React и TypeScript. Веб-версия переносит основные сценарии iOS-приложения в возможности браузера. Интерфейс на русском языке; базовое расписание работает локально и не требует аккаунта или API-ключей.

## Что реализовано

### Расписание и задачи
- 24-часовой круговой циферблат, указатель текущего времени и перенос задач перетаскиванием.
- Режимы циферблата: полные сутки, день, ночь и автоматическое переключение.
- Формат времени 24 часа или AM/PM.
- Создание, редактирование, удаление и отметка выполнения задач.
- Название, заметка, эмодзи, пользовательский цвет, категория, участники, напоминание и повтор ежедневно/еженедельно.
- Переключение дат и категорий; входящие задачи без назначенного времени.
- Календарь по неделям и месяцам; вертикальная лента суток.
- Светлая/тёмная темы и адаптивная компоновка для компьютера и телефона.

### AI-планировщик
- Разбор текста на несколько задач с временем и датой.
- Локальный разбор распространённых фраз на русском и английском без API-ключа.
- Разбор до 3 изображений расписания/заметок с помощью Gemini.
- Предпросмотр результата перед добавлением в расписание.
- AI-инсайты по планированию дня; локальная аналитика доступна без AI.
- AI API находится в app/api/ai/route.ts; секретные ключи провайдеров не отправляются в браузер.

### Аналитика
- Суммарная длительность задач и процент выполнения.
- Распределение времени по категориям и баланс работы с остальными делами.
- Тепловая карта занятости по часам и список рабочих блоков.
- Пять локальных наблюдений по расписанию; при настроенном Groq можно запросить AI-инсайты.

### Данные и интеграции
- Автосохранение задач и настроек в localStorage.
- Резервная копия и восстановление в JSON.
- Импорт/экспорт календарных событий в формате .ics.
- Настраиваемые браузерные уведомления для задач с напоминанием.
- Необязательная регистрация и вход через Supabase Auth.
- Необязательная ручная синхронизация задач через Supabase с Row Level Security.
- Просмотр размера локального хранилища и очистка задач с подтверждением.

## Требования для Windows

1. Установите Node.js LTS: https://nodejs.org/
2. Установите Git for Windows: https://git-scm.com/download/win
3. Откройте PowerShell и проверьте:

```powershell
node --version
npm --version
git --version
```

## Запуск

```powershell
git clone https://github.com/r1demachine/dayrhythm-web.git
cd dayrhythm-web
npm install
npm run dev
```

Откройте http://localhost:3000. Остановить сервер можно клавишами Ctrl+C.

## Проверка перед изменениями и PR

```powershell
npm run lint
npm run build
```

## Включение AI

AI-планировщик может обрабатывать простые фразы локально. Для AI через внешнего провайдера:

1. Скопируйте .env.example в .env.local.
2. Создайте API-ключ в кабинете нужного провайдера:
   - Groq: https://console.groq.com/keys
   - Gemini: https://aistudio.google.com/apikey
3. Заполните GROQ_API_KEY и/или GEMINI_API_KEY в .env.local. Модели можно настроить через GROQ_MODEL и GEMINI_MODEL.
4. Перезапустите npm run dev.

Пример переменных окружения:

```dotenv
GROQ_API_KEY=
GROQ_MODEL=llama-3.3-70b-versatile
GEMINI_API_KEY=
GEMINI_MODEL=gemini-3.8-flash
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
```

Не добавляйте заполненный .env.local в Git и никогда не передавайте API-ключи в браузерном коде. Gemini используется для анализа изображений: до 3 изображений на запрос, каждое меньше 4 МБ.

## Необязательные аккаунты и облачная синхронизация

Облачный режим не нужен для базового использования. Для синхронизации между устройствами:

1. Создайте проект Supabase: https://supabase.com/
2. Добавьте Project URL и anon/publishable key в .env.local как NEXT_PUBLIC_SUPABASE_URL и NEXT_PUBLIC_SUPABASE_ANON_KEY.
3. В Supabase SQL Editor выполните supabase/schema.sql. Таблица использует Row Level Security, поэтому пользователь может читать и изменять только собственные строки.
4. Перезапустите приложение, откройте Настройки → Аккаунт и синхронизация, зарегистрируйтесь или войдите и нажмите Синхронизировать сейчас.

Service Role Key веб-клиенту не нужен. Не добавляйте его в переменные NEXT_PUBLIC_* и не помещайте в репозиторий.

## Ограничения веб-версии

- В отличие от приложения iOS, браузер не получает прямой доступ к Apple Calendar и Reminders через EventKit. Для обмена событиями используется импорт/экспорт .ics.
- Browser Notifications требуют разрешения пользователя и срабатывают, пока веб-приложение открыто. Это не гарантированные фоновые iOS-напоминания.
- iOS WidgetKit, Live Activities/Dynamic Island, CoreMotion tilt и системные Apple Sign In/Reminders не перенесены как нативные функции. При поддержке браузера сайт можно установить как PWA.
- Supabase sync запускается вручную на экране настроек; аккаунт и облако необязательны. Без Supabase задачи остаются в локальном хранилище данного браузера.
- AI зависит от настроенных внешних ключей, доступности провайдера и его лимитов.
