# DayRhythm Web

Браузерный планировщик дня на 24-часовом круговом циферблате. Русский интерфейс, адаптация для Windows и iPhone, хранение задач локально в браузере без аккаунта и сервера.

## Возможности

- Круговой 24-часовой циферблат и управление задачами.
- Timeline — хронологический список задач выбранного дня.
- Входящие — захват задач без даты и перенос в расписание.
- Аналитика — распределение времени по категориям, почасовая диаграмма и статистика выполнения.
- AI-планировщик через серверный endpoint Groq (требуется API-ключ).
- Настройки темы, импорт/экспорт JSON и локальное хранилище.
- Режим **«Водоворот»**: 12-часовой циферблат, дуги с переменной толщиной, полупрозрачное будущее на 18 часов, симулятор времени и демо-дела.
- Добавление дел с собственным цветом и временем окончания, включая переход через полночь.

## Возможности первой версии

- Круговой циферблат на 24 часа с цветными секторами задач.
- Добавление, редактирование, удаление и отметка выполнения задач.
- Категории и цветовая маркировка.
- Перенос задачи по времени перетаскиванием на циферблат или редактированием времени.

- Светлая и тёмная темы.

- Адаптивная раскладка для компьютера и телефона.

1. Установите Node.js LTS: https://nodejs.org/
2. Установите Git for Windows: https://git-scm.com/download/win
3. Откройте PowerShell и проверьте:
   ```powershell
   node --version
   npm --version
   git --version
   ```

## Запуск

В PowerShell перейдите в папку, где хотите хранить проект:

```powershell
git clone https://github.com/r1demachine/dayrhythm-web.git
cd dayrhythm-web
npm install
npm run dev
```

Откройте http://localhost:3000

Чтобы остановить сервер, вернитесь в PowerShell и нажмите Ctrl+C.

## Настройка AI-планировщика

1. Создай API-ключ в [Groq Console](https://console.groq.com/keys).
2. В корне проекта скопируй `.env.example` в `.env.local`.
3. В `.env.local` заполни `GROQ_API_KEY=твой_ключ`.
4. Перезапусти сервер разработки: останови его через Ctrl+C и выполни `npm run dev`.

Ключ читается только сервером и не встраивается в браузер. Без ключа остальные разделы работают, но AI-разбор будет отключён.

## Настройка циферблата «Водоворот»

Геометрия отделена от React в чистом модуле `app/dial-geometry.ts`: `ribbonSamples` рассчитывает точки, `ribbonPath` строит сглаженный замкнутый контур, `ribbonSegments` формирует короткие залитые сегменты для затухания. Все основные параметры находятся в объекте `DIAL_CONFIG` в начале этого файла.

- `R0`, `W0` — радиус и полутолщина главного кольца.
- `R_in`, `w_past_min`, `pastFadeHours`, `pastEasePower`, `pastOpacityPower` — глубина сжатия и скорость затухания прошлого.
- `R_out`, `w_min`, `farOpacity`, `transitionHours`, `horizonHours` — радиус, толщина и прозрачность дальних дел.
- `sampleMinutes`, `segmentMinutes`, `segmentOverlapMinutes` — гладкость контура и сегментов; уменьшение шага увеличивает количество SVG-точек.
- `laneGap`, `maxLanes`, `currentWidthScale` — расстояние между пересекающимися делами и усиление текущего.

Для локальной проверки времени открой страницу в режиме разработки с параметром, например `http://localhost:3000/?now=09:00`, `?now=15:00`, `?now=21:00` или `?now=03:00`. Параметр активирует симуляцию только в режиме разработки. Кнопка «Демо-дела» добавляет перекрывающиеся задачи и дела, переходящие через полночь.

## Важно про данные

Задачи сохраняются только в localStorage браузера на конкретном устройстве. Они не синхронизируются автоматически между Windows и iPhone и могут быть удалены при очистке данных сайта. Пока не очищайте данные сайта, если хотите сохранить расписание.
